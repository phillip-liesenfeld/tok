# The Parliament's verdicts

Personal details were removed from these verdicts before publishing, and links point at the renamed files. Nothing else was changed.

Each sitting gave one set of questions about Tok to a panel of Claudes (Opus, Sonnet, Haiku, and later a Stranger who knew nothing about Tok), each with one lens and some with a veto. They wrote blind; the chair, the Claude Code session building Tok, wrote the verdict with every vote and dissent on the record. They are all Claude, so this is a design process, not an independent review.
